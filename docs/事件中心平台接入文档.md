# 事件中心平台接入文档

## 接口信息

- **接口路径**: `/api/v1/events/webhook`

- **请求方式**: `POST`

- **Content\-Type**: `application/json`

完整地址示例：

- `https://eventapi.bssrvc66.com``/api/v1/events/webhook`

## 鉴权方式

服务端读取环境变量 `WEBHOOK_TOKEN` 作为鉴权令牌。

请求时可任选其一：

1. Header 方式（推荐）

    - `X-Webhook-Token: <WEBHOOK_TOKEN>`

2. Bearer 方式

    - `Authorization: Bearer <WEBHOOK_TOKEN>`

若未配置或鉴权失败，返回 `401`。

### 4\.3 Java（JDK 11\+，HttpClient）

```Plain Text
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.nio.charset.StandardCharsets;

public class WebhookCaller {
    public static void main(String[] args) throws Exception {
        String url = "http://127.0.0.1:8001/api/v1/events/webhook";
        String token = "ec_webhook_2026_5f8a9d3c7b1e4a62b9c4d8f1a6e3c0";

        String jsonBody = """
            {
              "source_system": "Kubernetes",
              "occurred_at": "2026-05-06 14:42:00",
              "action": "update",
              "resource": "service/digi-grayscale-webhook",
              "operator": "system",
              "summary": "Selector 变更",
              "raw_payload": {
                "cluster": "poc-app-ack-cluster",
                "namespace": "k8s"
              }
            }
            """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create(url))
            .header("Content-Type", "application/json")
            .header("X-Webhook-Token", token)
            .POST(HttpRequest.BodyPublishers.ofString(jsonBody, StandardCharsets.UTF_8))
            .build();

        HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println("status=" + response.statusCode());
        System.out.println(response.body());
    }
}
```

### 4\.4 Go（net/http）

```Plain Text
package main

import (
        "bytes"
        "fmt"
        "io"
        "net/http"
        "time"
)

func main() {
        url := "http://127.0.0.1:8001/api/v1/events/webhook"
        token := "ec_webhook_2026_5f8a9d3c7b1e4a62b9c4d8f1a6e3c0"

        body := []byte(`{
  "source_system": "Kubernetes",
  "occurred_at": "2026-05-06 14:42:00",
  "action": "update",
  "resource": "service/digi-grayscale-webhook",
  "operator": "system",
  "summary": "Selector 变更",
  "raw_payload": {
    "cluster": "poc-app-ack-cluster",
    "namespace": "k8s"
  }
}`)

        client := &http.Client{Timeout: 30 * time.Second}
        req, err := http.NewRequest(http.MethodPost, url, bytes.NewBuffer(body))
        if err != nil {
                panic(err)
        }
        req.Header.Set("Content-Type", "application/json")
        req.Header.Set("X-Webhook-Token", token)

        resp, err := client.Do(req)
        if err != nil {
                panic(err)
        }
        defer resp.Body.Close()

        respBody, _ := io.ReadAll(resp.Body)
        fmt.Printf("status=%d\n%s\n", resp.StatusCode, string(respBody))
}
```

### 4\.5 Python（requests）

```Plain Text
import requests

    url,
    json=payload,
    headers={"X-Webhook-Token": token},
    timeout=30,

print(resp.text)
```

## 响应说明

### 5\.1 成功响应（HTTP 200）

```Plain Text
{
  "code": "SUCCESS",
  "message": "入库成功",
  "data": {
    "event_uuid": "f4d1c9f6-6af9-4db4-bf13-0f0a6b8f8f8f",
    "action": "改"
  }
}
```

### 5\.2 失败响应

统一结构：

```Plain Text
{
  "code": "错误码",
  "message": "错误说明"
}
```

常见错误码：

- `INVALID_JSON`: 请求体不是 JSON 对象（HTTP 400）

- `VALIDATION_ERROR`: 字段缺失/格式非法/长度超限（HTTP 400）

- `UNAUTHORIZED`: Token 无效或缺失（HTTP 401）

- `AUTH_CONFIG_ERROR`: 服务端未配置 `WEBHOOK_TOKEN`（HTTP 401）

- `DB_ERROR`: 数据库异常（HTTP 500）

- `INTERNAL_ERROR`: 其他内部异常（HTTP 500）

## 与表结构映射关系

入库表：`platform_event`

- `event_uuid`: 服务端自动生成 UUID

- `source_system`: 来自请求 `source_system`

- `occurred_at`: 来自请求 `occurred_at`

- `action`: 来自请求 `action`（映射后写入中文）

- `resource`: 来自请求 `resource`

- `operator`: 来自请求 `operator`（默认 `system`）

- `summary`: 来自请求 `summary`

- `raw_payload`: 来自请求 `raw_payload`（不传则整条请求）

- `ingested_at`: 数据库默认 `current_timestamp(6)` 自动生成
