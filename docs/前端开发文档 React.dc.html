/admin 按身份落到能进的第一页；旧地址 /connections、/settings 等重定向到 /admin/*，query 一并带过去。守卫依次判断：

  • 没有会话标记 → 登录页；首次进入先 fetchMe()，失败则登出。
  • 落地页：一个菜单都没有的账户回登录页；只开了数据查询的业务方送去 /query。
  • 管理后台：只有平台管理员（auditor 页审计员也行），否则回总览。
  • 从别处走进管理后台时调 POST /admin/enter；IP 不在白名单内就地拦下并提示。
  • 菜单不可见 → 总览。
// router/index.ts（节选）
loader: async () => {
  const r = await guard(meta, currentMeta())
  if (r === true) return null          // 放行
  if (r === 'stay') throw replace(here) // 就地拦下，留在原页
  throw redirect(r)
}

RouterProvider 设了 useTransitions={false}：默认的低优先级渲染会让地址先变、页面晚几十毫秒才换，这期间的点击会落在旧页上。每个页面挂了 RouteError，一页渲染出错只影响那一页。

Web 命令行由 AppLayout 放在 KeepAlive 里常驻：切到别的菜单时 DOM 从页面上摘下，组件不卸载，标签、会话和未提交的事务都还在。

Stores
Store内容
auth会话标记、me，以及由 me 推出的 menus / isAdmin / isAuditor / onlyQuery / firstVisibleRoute；待办与待审批数；login、loginSSO、fetchMe、logout、clearSession

snippets终端快捷脚本，所有终端标签共用一份
  • 组件里按字段取：useAuthStore((s) => s.me)；选择器不要返回新建的对象或数组，会无限渲染。
  • 事件与异步流程里用 useXxxStore.getState()，不要拿 await 之前解构出来的旧值。
  • 不该依赖 React 的 lib 用 lib/observable.ts 存全局状态（品牌、确认框），组件用 useObservable 读。

写完马上要读、或者交给 xterm / WebSocket / 计时器的值用 useStateRef，回调用 useEvent，避免闭包拿到旧值。防双击要用 ref，不能只靠 state。

05 核心模块实现要点

Module Notes

5.1 Web 命令行终端

左侧实例树（DbTree）、中间 xterm、右侧风险检查（RiskInspector）。会话逻辑全在 terminal/sessionController.ts，不依赖渲染闭包；TerminalSession.tsx 只负责渲染和订阅。行编辑器、SQL*Plus / mysql 客户端命令、补全、结果表格都在 lib/ 里，可以单测。提交命令先做风险预检，需要审批就弹原因框，否则经 WebSocket 下发：

// 示意，真实流程见 sessionController.ts
const r = await api.riskCheck(conn.id, sql, database) // 带库名：执行窗口按库判
if (r.requiresApproval) openApproval(sql, r)          // 填原因后提交审批
else if (sendExec(sql, '') !== 'ws') await execREST(sql) // WS 不可用时退回 REST

预检只决定要不要先问一句；放行、审批、拦截以及 MFA 都由网关在执行时重新判定。每个标签有自己的会话标识，网关为它独占一条数据库连接，断线重连不丢事务。

5.2 脚本上传与扫描

脚本随 POST /scripts/scan 提交（文本或已上传脚本的编号），ScriptScanModal 展示逐条判定与统计。带 progressId 时轮询 /scripts/progress/:id 显示进度，可取消。含高危语句时按钮变成提交审批；超时上限 120 秒。

5.3 权限矩阵与菜单权限

PermissionsView 的矩阵按「能力 × 分层」展示，单元格点击循环 allow → approve → deny，保存到 PUT /roles/:id/capabilities；菜单开关保存到 /menus，标签范围保存到 /tags。

5.4 高危命令规则

字典按分层切换，徽标点击循环 拦截（high）→ 审批（mid）→ 放行（off），调用 PATCH /risk-commands/:name。分层由后端返回（envtier store），不写死。

5.5 审批

列表分「我的 / 全部」并在服务端分页、筛选。通过不等于执行：批准之后由发起人、或够得到该实例的人，在这里或总览点「执行」。拉取脚本全文时换了单，旧响应作废，不会盖在新单上。页上有执行中的单时每 3 秒刷新，直到有结论。在聊天卡片上决定的单显示渠道，驳回的显示拒绝原因（纯文本）。

审批机器人：用户菜单的 ChatBindModal（打开菜单时才问有没有开着的渠道，没有就不显示这一项；显示绑定码时才轮询，关掉即清）；设置 › 审批的 ChatChannelsPanel，表单随整页保存，状态只在该页签可见时每 5 秒取一次。

5.6 发布

ReleasesView 是列表与轮询，ReleaseDetailPane 是详情，ReleaseForm 是新建。只要还有待执行、运行中或等待的单就每 2.5 秒轮询；列表与详情请求都带编号，迟到的响应作废。

5.7 管理后台

管理后台有独立的空闲超时（useAdminIdle）：到点退回用户后台，不登出；有没保存的改动（useUnsavedFlag 登记）则锁住当前页，重新进入后原地继续。有操作时节流上报心跳。

06 API 对接契约

API Contract

统一前缀 /api/v1，响应包 { code, msg, msgRef, data }。会话在 HttpOnly Cookie 里，脚本读不到；前端只有会话标记（localStorage）和 CSRF Cookie，写操作把它放进 X-CSRF-Token。msgRef 是报错的机器可读身份，拦截器按界面语言重新渲染 msg。

07 三层权限控制（前端）

Client-side Authorization

前端只做展示层收敛（藏入口、灰按钮），真正的拦截以后端为准：

  • 菜单层：路由守卫 + 侧栏，按 menus 渲染；管理后台另按角色判断。
  • 能力层：能不能做由后端按单判定，例如审批单带回 canDecide / canExecute / canCancel，前端据此显示按钮。没有 v-permission 一类的指令。
  • 命令层：提交前 /risk/check 决定是否先填审批原因；执行时网关重新判定。

08 国际化与主题

i18n & Theme
  • 词条：locales/zh.json5 与 en.json5 必须同步改。裸的 @、|、{ 是消息语法，要写成字面量插值；写坏的词条在构建时就报错。
  • 取词：组件用 useI18n() 的 t / te，切换语言会重新渲染；lib 里用 i18n.global。
  • 后端文案：服务端的中文带着 ref（msgRef、titleRef、commandRef …），英文界面按 ref 渲染，认不出就原样显示。
  • 主题：<html data-theme> 切换深 / 浅，默认浅色，可跟随系统；业务样式只用语义 token，如 var(--surface-card)。
  • 实例名、SQL、人名等数据不翻译。

09 样式隔离

Scoped Styles

组件旁边放 Foo.scoped.css，在 Foo.tsx 里 import 即可。构建时 build/scopedCss.ts 给该文件的所有 JSX 标签加作用域属性，选择器限定到同一属性，@keyframes 自动改名；支持 :deep() 与 :global()。

  • 一个大组件拆成多个 .tsx 时，每个都要 import 同一份 scoped.css，否则样式丢失。
  • 会被父组件装饰的组件要把 ...rest 展开到根元素并合并 className。
  • 可复用组件的根元素不要用 overlay、card、modal 这类通用类名（有单测把关）。

10 终端 WebSocket 协议

握手靠会话 Cookie，另用子协议 aegisdb-csrf + CSRF 值证明不是别的站点发起的。lib/wsTerminal.ts 负责心跳与指数退避重连。

11 构建、规范与交付

Build & Conventions
  • 命令：npm run dev · npm run build · npm run type-check · npm run test:unit · npm run test:e2e。
  • 命名：组件 PascalCase；hook 与 store 用 useXxx；类名与 data-testid 是 e2e 的契约，改动要同步用例。
  • 类型：types/ 与后端 DTO 对应；接口数据按可能缺字段处理（?.、?? []），渲染时抛错会让整页换成错误提示。
  • 环境变量：VITE_API_BASE、VITE_WS_BASE，默认同源 /api/v1。
  • 单测：只测 lib 的纯逻辑与词条，在 Node 里跑。
  • e2e：每个用例给接口打桩，没打桩的一律 502；独立端口 5174。
  • 未引入：ESLint、Prettier、zod、Vitest、组件库。
