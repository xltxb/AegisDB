# 06 · SQL 脚本上传扫描 + 整脚本审批/执行

Status: ready-for-agent

## What to build

DBA 上传 `.sql` 脚本，系统按 `;` 拆分语句、剔除行/块注释、逐条按当前环境字典判级，给出统计概览 + 逐条明细报告；检出高危/需审批语句时执行入口变为"提交审批后执行"，全部安全时可直接执行并回显。扫描规则与 03/04 终端实时拦截、05 高危字典完全一致。

- 后端：`POST /scripts/scan`（multipart `.sql` 上传 → 拆句/剔注释/逐条判级，无 WHERE 的 DELETE/UPDATE 单独标记 → 返回统计 + 逐条明细）；`POST /scripts/execute`（全安全直接代执行；含高危则整脚本转审批，复用 04 审批单与代执行）。
- 前端：终端域 ScriptScanModal——上传 `.sql`、展示统计概览（总语句/高危/需审批/安全）与逐条风险标签；主按钮按结果在"直接执行"/"提交审批后执行"间切换；执行结果回显终端。

## Acceptance criteria

- [ ] 上传 `.sql` 后按 `;` 拆句并剔除行/块注释（FR-SQL-01）
- [ ] 逐条判级（高危/需审批/安全），无 WHERE 的 DELETE/UPDATE 单独标记（FR-SQL-02）
- [ ] 报告含统计概览 + 逐条明细及风险标签（FR-SQL-03）
- [ ] 含高危语句时整脚本转审批后才执行；全安全时直接执行回显（FR-SQL-04）
- [ ] 字典在 05 调整后，扫描判定结果同步变化（与终端一致，FR-SQL-05）

## Blocked by

- 04（复用审批单与代执行闭环）
- 05（复用高危命令字典）
