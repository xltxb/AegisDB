# 08 · 审计日志查询（筛选 + 时间范围 + CSV 导出）

Status: ready-for-agent

## What to build

审计员/管理员在 `/audit` 检索全量命令留痕：每条记录含时间、操作人、实例、命令全文、风险等级、结果（执行/审批中/拒绝/告警）与审批单号；支持按风险（全部/高危/中/低）与时间范围（24h/7天/30天）服务端筛选，并导出含完整命令与审批链的 CSV。审计记录由 03 写入（哈希链），本片负责查询与导出（含被拦截、被拒绝的命令）。

- 后端：`GET /audit`（风险 + 时间范围服务端过滤、分页）、`GET /audit/export`（CSV，与当前筛选条件一致）。读 `tbl_audit_log`，校验哈希链完整性。
- 前端：`/audit` 页 + `audit` store（rows/filter/timeRange/fetch/export）。日志行表 + 风险/时间范围筛选 + 一键导出 CSV。

## Acceptance criteria

- [ ] 列表展示时间/操作人/实例/命令/风险/结果/审批单号（FR-AUD-01）
- [ ] 按风险（全部/高危/中/低）与时间范围（24h/7天/30天）服务端过滤（FR-AUD-02）
- [ ] 被拦截与被拒绝的命令同样可检索（审计完整性验收点）
- [ ] CSV 导出含完整命令与审批链，且与当前筛选条件一致
- [ ] 哈希链 append-only 校验通过（防篡改）

## Blocked by

- 03（审计记录与哈希链由风险引擎写入）
